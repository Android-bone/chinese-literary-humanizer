# Changelog

All notable changes to this project will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-22

### Added

- Initial public release of `chinese-literary-humanizer`.
- Three editing modes: cleanup, deep rewrite and literary commentary.
- Chinese-native diagnostics for AI traces, translationese, mechanical structure and typography.
- Conditional first-author voice guidance for WeChat articles and signed commentary.
- Six reference modules with pattern examples, complete rewrites and final-review scoring.
- Fact, source, causality, HTML, Markdown, link and image-position preservation rules.
